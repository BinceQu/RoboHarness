Abstract

The rise of large language models (LLMs) has opened a path toward generalist embodied AI, raising the question of how LLMs can act in the physical world. One straightforward approach is training the model to generate actions: collect robot-action data and video demonstration, refine LLM architecture with an action head, and train a vision-language-action (VLA) model at scale.

However, we argue that coding agents have the potential to realize generalist embodied manipulation. All they need is a simple yet effective robot harness. We present RoboHarness: a robotic harness that gives LLM agents a visual-geometric control panel so that they can directly understand and invoke embodied tasks. With RoboHarness, Qwen3.8-Flash-Next outperforms state-of-the-art VLA models on BEHAVIOR Challenge 2025 tasks. The implementation is open source.

01 / Method

A visual-geometric control panel for embodied tasks

Without training models, RoboHarness combines visual clicks, keypoint tracking, and geometric constraints to provide an embodied control panel for an LLM agent.

Persistent visual grounding

Track points. Recover geometry. Compose actions.

The LLM selects one or more points of interest that are visible in the head camera. The harness continuously tracks each marked point across successive frames, recovers metric distance from depth, and back-projects the pixel coordinate into the robot camera frame.

The model supplies points and their spatial relations; the harness solves and executes the corresponding action. The same interface supports both keypoint-and-constraint actions and direct robot adjustment.

02 / Generalization

Across objects and robot data

The task is to pick up each of the 100 objects and place it in the embodiment and simulation environment on which the corresponding model was trained. For ASPIRE and RoboHarness, the object is placed on the floor and the robot starts from a stooping pose.
