01 / Method

Geometry state for
spatial grounding.

Without training models, RoboHarness combines visual clicks, keypoint tracking, and geometric constraints to provide an embodied control panel for an LLM agent.

Track keypoints.

The LLM marks points of interest on a 2D image and continuously receives their positions via optical-flow tracking and depth back-projection; with this information, it composes accurate primitive actions to perform complex manipulation.

Keypoint-constraint tools.

The model supplies a set of input points together with their spatial relations, and the harness automatically solves and executes the corresponding action.

  1. 01[ ]

    Select points

    The LLM selects one or more points of interest that are visible in the head camera.

  2. 02>_

    Track keypoints

    Harness continuously tracks each marked point across successive head-camera frames.

  3. 03⌖

    Recover depth

    The latest 2D location is projected onto the depth view to recover the metric distance.

  4. 04Σ

    Back-project

    The pixel coordinate and depth are then back-projected into the robot camera frame.

Generalization
across objects.

The task is to pick up each of the 100 objects, and to place each object in the embodiment and simulation environment on which the corresponding model was trained. For ASPIRE and RoboHarness, the object is placed on the floor and the robot starts from a stooping pose.
