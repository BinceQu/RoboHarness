01 / The method

Track. Constrain.
Act. Verify.

RoboHarness gives an agent a shared geometric language for perception and action. Tracked image points become robot-frame coordinates; geometric tools turn constraints into executable motions.

Keep the geometry grounded.

Track a visual keypoint across observations. Sample its depth and back-project it into the robot's coordinate frame. The agent can refer to the same point as the scene changes.

Compose actions as constraints.

Align a gripper, move a tracked point, or adjust the robot's pose. Embodied skills compose these tools into longer interactions.
